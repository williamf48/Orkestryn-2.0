# Orkestryn research rounds

Each round asks a question that could fail. Record the comparison, unit, denominator, inclusion rules and stopping rule before running it. Keep completed outputs unchanged and put follow-up experiments in a new round. Do not count multiple budgets or matched wordings as independent participants or independent scenarios.

Round 001 is an offline experiment. It uses no real system operations, paid inference or volunteers. The authenticated studies dashboard links the same evidence as the portable command:

    py -3 Orkestryn.pyz --research-round round-001.zip

From source use `python run.py --research-round round-001.zip`. The ZIP contains:

| File | How to use it |
| --- | --- |
| protocol.json | Read the frozen questions, predictions, sampling and sources before interpreting results. |
| summary.json | Examine numerators and denominators, including false alarms and unnecessary holds. |
| cases.json | Reconstruct the 156 toy action plans, initial states, permissions and independent history labels. |
| records.jsonl | One complete test observation per line. Handoff and missing-return rows carry their own input factors. |
| failures.jsonl | Look up the matching ID in the full records. A failure can be an omitted violation, a wrong action citation, an incorrect recommendation or a comparison changed by missing data. |
| SHA256SUMS.txt | Verify each uncompressed file; ZIP compression can differ across systems. |

The first-action lookup knows the family and that the trace is harmful; it is a diagnostic of a timing shortcut. The snapshot can only decide whether harm is present at the end. The full guard is separately implemented from the history-based scorer but operates in the same toy world. Each path uses a matched synthetic design. The budget bound applies only to identical public inputs on this finite case set and to a deterministic rule with no false alarms. It is not an estimate of a language model's capabilities. The handoff controls are explicit decision rules, not measured LLM agents.

Human missing-return bounds cover all feasible completions of the three changed decisions in each issued but unreturned packet. Rates are over issued packets, not people known to have opened them. Negative values of highlighting minus standard favor highlighting on unauthorized approvals only. Timeouts and unnecessary holds must still be reported. This range is not a confidence interval and it does not address recruitment or assignment bias.

Round 002 adds separate labels for permission violations, realized protected-state harm at any point in replay, and legitimate task completion. Its frozen design is in app/oversight_round_002.json. Rebuild the evidence using the portable app with --research-round-2 and a new ZIP path. The evidence includes every scored observation, inputs, fitted trees, the discrepancy index, the indeterminate index and internal file hashes. The 48 older plans and the 84 fictional booking plans are authored; findings do not estimate production performance. Participant scenarios are simulated; the live paired-packet report uses only the workspace's returned, non-practice records. All new comparisons run locally with no service credentials.

Round 003 tests an inspector that can skip permitted, typed read-only actions; every inspected header costs an explicit share of a full-action read. The same plan is also tested with more work to verify and the same outcome. A separate handoff experiment tests copied recommendations and shared source errors. A human-review gate requires both fewer unauthorized approvals and preserved timely correctness. The local protocol and all raw decisions, discrepancies, and unknowns are in the output of --research-round-3 NEW_ZIP. Published human decisions and public retail/airline simulations are separate, pinned secondary datasets in the private notebook, not bundled into the app or pooled as human evidence for Orkestryn.

Round 004 uses incomplete histories and decision revisions. From Safety Lab > Research studies, inspect a case at different checkpoint intervals, compare approval receipts and refresh policies, and open a timing JSON locally. The research controls only model decisions in memory. Run `--research-round-4 NEW_ZIP` for the three deterministic case studies, and `--research-time-4 NEW_JSON` for a separate elapsed-time benchmark (seven workers, run sequentially). Repeated timings need not match; decisions should. The private notebook includes an independent analysis of public telecom reference annotations and the complete errors and uncertainty records.
